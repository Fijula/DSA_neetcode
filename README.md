Every file follows the same layout:

1. **Problem statement** — description + example in comments
2. **Case 1: Brute force** — the naive approach
3. **Case 2: Optimal** — the interview-ready approach
4. **Case 3: Short** — a concise Pythonic version
5. **`__main__`** — runnable test cases

Time & space complexity are noted under each function.
